# 🎮 Simple Game Main Menu

A Unity project focused on recreating the core features commonly found in modern game main menus.

This project is designed as a portfolio piece to demonstrate clean architecture, UI programming, animations, and game systems implementation in Unity.

---

## 📌 Project Goal

The purpose of this project is to build a complete, modern, and reusable **Game Main Menu System** similar to those used in AAA and indie games.

Instead of creating a full game, this project focuses on implementing the systems that players interact with before entering gameplay.

---

- Play Button
- Continue Button
- New Game
- Load Game
- Exit Game

- Audio Settings

  - Voice Volume
- Graphics Settings
  - Resolution
  - Fullscreen
  - Quality Levels
  - VSync
  - FPS Limit

  - Controller Support

### 💾 Save & Load
